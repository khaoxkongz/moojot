# บันทึกการเงินบนมือถือ

ภาษาร่วมสำหรับรายการการเงินและการจัดกลุ่มรายการในแอปหมูจดบนมือถือ

## Language

**ธนาคารของรายการ**:
ธนาคารที่ใช้จัดกลุ่มรายการการเงิน รายการของธนาคารเดียวกันอยู่ในกลุ่มเดียวกัน แม้ผู้ใช้จะมีหลายบัญชีที่ธนาคารนั้น
_Avoid_: บัญชีธนาคารรายบัญชี (เมื่อหมายถึงกลุ่มธนาคาร)

**บัตรของรายการ**:
บัตรเครดิตที่รายการนั้นใช้จ่าย ระบุในแอปด้วยชื่อบัตรและเลขท้ายสี่หลัก

**วันรายการ**:
วันที่อ้างอิงของรายการการเงิน ใช้วันที่ผู้ใช้เลือกสำหรับรายการจดเอง วันที่จากสลิป หรือวันครบกำหนดสำหรับรายการจดซ้ำ

**เวลาทำรายการ**:
เวลาที่เหตุการณ์ทางการเงินของรายการเกิดขึ้นตามหลักฐานของรายการ อาจไม่มีข้อมูลนี้เมื่อทราบเพียงวันที่
_Avoid_: เวลาบันทึก

**เวลาบันทึก**:
เวลาที่รายการถูกบันทึกเข้าแอปหมูจด
_Avoid_: เวลาทำรายการ
